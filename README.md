# Diploma Exam Prep

Study notes for the Buddhism Diploma exams.

- **[Pali Charts](https://chujieying.github.io/buddhism-diploma/)**: all Pali charts on one page (alphabet, declensions, conjugations, pūjā and vandanā) with a tap-to-reveal quiz mode.
- **[Pali Coach](https://chujieying.github.io/buddhism-diploma/coach.html)**: simple lessons, memory tricks, flashcards and practice tests.
- **[Geo Expansion](https://chujieying.github.io/buddhism-diploma/geo.html)**: Geographical Expansion of Buddhism, one lesson per exam question with explain-like-I'm-5 boxes, mnemonics, a map, answer outlines, flashcards, a quiz and a timed essay drill using past-year questions.
- **[Overlaps](https://chujieying.github.io/buddhism-diploma/overlaps.html)**: a slide deck for the six topics that appear in more than one paper (five precepts, ten deeds and kamma, Four Noble Truths and the Path, five aggregates, the Second Council split, mindfulness). Mind maps and memory tricks first, then a full model answer for each with what to add for each paper.
- **[Decks](https://chujieying.github.io/buddhism-diploma/decks.html)**: one revision deck per paper (Early Buddhism, Social Dimensions, Geo Expansion, Counselling, Pāli), built from the principal's exam questions. Each question has a mind map, memory tricks and an answer skeleton, with a cheat sheet of every memory trick at the end.
