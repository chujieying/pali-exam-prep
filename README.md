# Diploma Exam Prep

Study notes for the Buddhism Diploma exams.

- **[Pali Charts](https://chujieying.github.io/pali-exam-prep/)**: all Pali charts on one page (alphabet, declensions, conjugations, pūjā and vandanā) with a tap-to-reveal quiz mode.
- **[Pali Coach](https://chujieying.github.io/pali-exam-prep/coach.html)**: simple lessons, memory tricks, flashcards and practice tests.
- **[Geo Expansion](https://chujieying.github.io/pali-exam-prep/geo.html)**: Geographical Expansion of Buddhism, one lesson per exam question with explain-like-I'm-5 boxes, mnemonics, a map, answer outlines, flashcards, a quiz and a timed essay drill using past-year questions.
